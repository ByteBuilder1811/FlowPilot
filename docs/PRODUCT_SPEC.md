# FlowPilot – product spec (as built)
Positioning: *build, execute, inspect, recover, replay, test, improve* agent automations with reliability as the differentiator.
Modules: Workflow Studio, Agent Workspace, Live Execution Center, Reliability Engine, Failure Lab, Version Comparison, Integrations/Templates, Settings. See ARCHITECTURE.md/EXECUTION_MODEL.md for behavior and README.md for the demo journey.
Out of scope in this build: multi-user auth, memory for agents, parallel branches, cost estimation, a Code node, hosted deployment.
